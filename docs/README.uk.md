# Andrii Naumov: портфоліо (нотатки українською)

Англійський опис для GitHub лежить у [README.md](../README.md). Тут детальніше про те, як усе влаштовано.

Портфоліо на React + Vite (чистий JavaScript, без TypeScript) трьома мовами: EN, DE, UK.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173/
npm run build      # готовий сайт у папці dist/ (Vite + scripts/prerender.mjs)
npm run preview    # перевірити зібраний сайт локально
```

## Як це працює

**Hero: Розробка → Автоматизація → Запуск.** У `HeroScene.jsx` сторінка описана масивом `BLOCKS`: у кожного блоку є позиція і розмір у десктопній версії (`a`) та на телефоні (`b`). Блоки — це `RoundedBox` з drei з м'яким світлом (`Environment` + `Lightformer`, без файлів HDR) і тінню `ContactShadows`. Hero має висоту 360vh, а її вміст "прилипає" (`position: sticky`), тож ScrollTrigger рахує прогрес від 0 до 1. Три етапи:

1. **Розробка:** спершу видно креслення сторінки (пунктирні контури). Жовтий курсор, як у лого, переходить від елемента до елемента, і кожен "виростає" на своє місце з підписом тегу (`<header>`, `<h1>`, `<img>`…).
2. **Автоматизація:** курсор стає променем, який раз за разом сканує сторінку, а внизу задачі самі їдуть конвеєром через ворота `auto.py` і стають синіми (виконаними). Ця частина рухається сама, навіть коли скрол стоїть.
3. **Запуск:** сторінка перебудовується в мобільний макет, навколо з'являється телефон і мітка `● live`.

Межі етапів задані на початку `HeroScene.jsx` (`BUILD`, `AUTOMATE`, `SHIP`), а підписи під hero вмикаються в тих самих точках (`STAGE_STARTS` у `Hero.jsx`).

**Зміна мови.** `FlapText.jsx` розбиває заголовок на літери. Коли текст змінюється, кожна літера кілька разів перегортається (GSAP, `rotationX`) через випадкові букви і зупиняється на новій, як табло на вокзалі. Справжній текст лежить у прихованому `span` для скрінрідерів і SEO. Звичайний текст при цьому просто плавно з'являється (клас `is-switching` на `body`).

**Термінал.** Вивід зберігається не як готовий рядок, а як функція від `t()`, тому вся історія перекладається, коли змінюється мова.

**Мапа.** `scripts/build-map.mjs` один раз генерує сітку точок Європи з даних `world-atlas`. У цих даних (Natural Earth) Крим віднесено до Росії, тому скрипт примусово фарбує точки півострова як Україну. Маршрут — це SVG `path` з двох дуг, а `stroke-dashoffset` прив'язаний до скролу.

**Доступність.** Якщо в системі ввімкнено "зменшити рух" (`prefers-reduced-motion`), анімації вимикаються. 3D-сцена завантажується окремим файлом і не рендериться, коли hero поза екраном.

**Лоадер і завіса блокують сторінку.** Поки на екрані лоадер або завіса переходу, сторінку не можна прокрутити, клікнути чи відкрити термінал: `lockInteraction()` у `lib/motion.js` зупиняє Lenis і перехоплює колесо, дотики, клавіші й кліки. Кожен виклик повертає свою функцію `unlock`, і сторінка звільняється, коли розблокували всі.

**Плавність на слабких телефонах і повільному інтернеті.** Лоадер і завіса анімують тільки `transform` і `opacity` через CSS і Web Animations API (`element.animate`). Браузер виконує такі анімації окремо від JavaScript, тому вони не смикаються, навіть коли сторінка ще завантажується або за завісою будується нова сторінка. Лого для них (`GrowMark.jsx`) складене з HTML-блоків, обрізаних `clip-path`, бо частини SVG так анімувати не можна. 3D-сцена вмикається тільки після того, як лоадер зник (`loaderDone` у `lib/motion.js`), а на телефонах рендериться в трохи нижчій роздільності.

**3D на телефоні** займає все вільне місце між шапкою і текстом: `Hero.jsx` вимірює, де починається текст, а сцена підбирає масштаб під кожен етап. Коли заголовок зникає і лишається короткий підпис етапу, модель стає більшою.

**Картинки** лежать окремими файлами в `public/`: `favicon.svg` (з версією для темної вкладки браузера) і `apple-touch-icon.png` для іконки на головному екрані iPhone. Лого в шапці, лоадері й завісі — це компонент `LogoMark.jsx`, бо його частини анімуються окремо.

**Термінал.** Відкривається і закривається клавішею ліворуч від "1" на будь-якій розкладці: перевіряється фізична клавіша (`e.code === 'Backquote'`), а не символ. Тому працює і з українською (`'`), і з німецькою (`^`). Вікно терміналу прокручується колесом миші окремо від сторінки (атрибут `data-lenis-prevent`).

**Адреси й мови.** Німецька живе в корені: `/`, `/impressum`, `/datenschutz`. Англійська й українська мають префікс: `/en`, `/uk/impressum` тощо. Усі сторінки обробляє один маршрут (`Shell` в `App.jsx`), тому при зміні мови сторінка не перезавантажується: 3D-сцена і позиція скролу зберігаються.

**Визначення мови** (`lib/lang.js`). Коли людина вперше відкриває німецьку адресу без префікса, сайт по черзі перевіряє:

1. мову, яку вона вже обирала перемикачем (зберігається в `localStorage`);
2. мови браузера в порядку пріоритету;
3. часовий пояс пристрою (Київ → українська, Берлін, Відень, Цюрих → німецька);
4. якщо нічого не підійшло, залишається німецька.

Перенаправлення відбувається ще до першого рендеру, тому нічого не блимає. Посилання з явною мовою (`/en`, `/uk`, `/de`) завжди відкриваються як є. Жодних запитів до сторонніх API немає, тож для GDPR тут нічого додатково описувати не треба. Для пошуковиків додаються теги `hreflang`.

**Переходи між сторінками** (`lib/routing.jsx`). Посилання на Impressum, Datenschutz і назад ведуть через `TransitionLink`: знизу піднімається темна завіса, в ній "виростає" лого, під нею відкривається нова сторінка (вже прокручена вгору), і завіса йде вгору. Кнопки браузера "назад/вперед" показують другу половину переходу. Зміна мови завісу не показує, бо сторінка та сама.

**Мапа в "Шляху".** Після останнього пункту таймлайну є вільне місце (`padding-bottom` у `_journey.scss`), тож мапа залишається на екрані, поки Гаген загоряється, і з'являється підпис "Тепер я вдома в Гагені".

## Що треба зробити перед публікацією

1. **Impressum:** впиши справжню адресу в `src/data/site.js` (`IMPRINT`). У Німеччині сайт без Impressum може отримати претензію. Поки там приклад, `npm run build` виводить попередження.
2. **Домен:** впиши його в `SITE_URL` у `src/data/site.js` або змінною середовища в Cloudflare.
3. **CV:** поклади `Andrii_Naumov_CV_DE.pdf` і `Andrii_Naumov_CV_UK.pdf` у `public/cv/` і пропиши їх у `CV` у `src/data/site.js`.
4. **Німецькі тексти** (`src/locales/de.json`) дай перевірити носію мови.
5. **Цифри в проєктах:** додай реальні результати в `projects.featured` (наприклад, "скоротив підготовку проєкту з N годин до M хвилин").
6. Якщо зробиш open-source версію парсера, додай посилання в `PROJECT_LINKS.parser`.

## Деплой на Cloudflare

Проєкт підключений у Cloudflare як Worker зі статичними файлами (Workers & Pages → Create → Import a repository):

- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`
- Build variable: `SITE_URL` = `https://твій-домен` (без слеша в кінці)

`wrangler.jsonc` у корені каже Cloudflare віддавати папку `dist/`: `/en` відкриває `en.html`, невідомі адреси отримують `404.html`. Версію Node бере з `.node-version` (20). Кожен пуш у `main` перезбирає сайт. Свій домен підключається у вкладці **Domains** (або Settings → Domains & Routes → Custom domain).

Що робить збірка (`scripts/prerender.mjs`): для кожної адреси (`/`, `/en`, `/uk/impressum`…) створює окремий HTML з правильною мовою, заголовком, описом, `hreflang`, `canonical` і картинкою для превʼю (`public/og-image.png`). Ще `404.html`, `robots.txt` і `sitemap.xml` (коли задано `SITE_URL`).

У `public/` лежать файли для Cloudflare:

- `_headers` — заголовки безпеки (CSP, HSTS, заборона вбудовувати сайт у чужі iframe) і довгий кеш для `/assets/*`;
- `_redirects` — `/de/...` веде на корінь, `/en/` на `/en`.

У Cloudflare не вмикай Web Analytics, Rocket Loader і Zaraz: сайт обіцяє в Datenschutz, що нічого не відстежує, а CSP заблокує чужі скрипти. Якщо колись захочеш аналітику, треба оновити і політику конфіденційності, і CSP.

Перевірити збірку локально так, як її віддасть Cloudflare: `npm run build`, потім `npx wrangler dev`.
